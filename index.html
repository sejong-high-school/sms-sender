사용 방법 (How to use)

  1. 한국 전화번호를 입력하세요 (한 줄에 하나씩) (Enter South Korean phone numbers, one per line)
  2. 전송할 메시지를 작성하세요 (Write your message)
  3. 일괄 전송 모드를 선택하세요 (Choose bulk send mode)
  4. 전송 버튼을 클릭하세요 (Click the send button)
참고: 이 앱은 데모 목적으로 제작되었습니다. 실제 SMS 전송을 위해서는 적절한 SMS API 서비스가 필요합니다.

Note: This app is created for demonstration purposes. Actual SMS sending requires an appropriate SMS API service.
